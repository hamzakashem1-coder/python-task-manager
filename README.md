# Python CLI Task & Expense Manager

A lightweight, robust command-line interface (CLI) application built in Python designed to manage personal tasks and expenses with persistent local JSON file storage.

## Features
- **Interactive Terminal Menu:** Clean user experience with structured navigation.
- **Persistent Data Storage:** Automatically saves and loads records using Python's built-in `json` module (`tasks.json`).
- **Status Tracking:** Create items, categorize them, and mark them as completed.
- **Robust Input Handling:** Gracefully handles invalid inputs and empty entries.

## Technologies Used
- **Python 3**
- Native modules: `json`, `os`

## How to Run
1. Ensure you have Python 3 installed on your machine.
2. Clone or download this repository.
3. Open your terminal or command prompt in the project directory.
4. Run the application:
   ```bash
   python app.py
